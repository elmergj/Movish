Welcome to the Movish API documentation. This section introduces the project and guides you through the initial setup for local development.

> **Development status:** Movish is actively evolving. Some features and implementation details are provisional and may change as the domain model and API mature.

## What is Movish?

Movish is a platform for discovering, organizing, and following movies and TV shows. It is designed to let users search external catalogs, manage a personal library, create watchlists, mark favorites, and track the status of each title.

The platform consists of two independent projects. Movish API is the server-side application that provides the data and services required by the platform. Movish App is the client application that consumes the API and gives users access to those features on their devices.

## What is Movish API?

Movish API is a Java and Spring Boot backend that manages the core logic behind Movish App.

Its primary responsibility is to coordinate catalog data from external providers so that users can discover, organize, and follow movies and TV shows. The current codebase includes provider integrations and is designed to keep those external details behind application and domain-level boundaries.

The project includes integration code for providers such as The Movie Database (TMDB). Provider credentials and URLs are configured through environment variables and must not be committed to source control. Review each provider's documentation and terms of use before using its data.

Movish API also provides services for user registration, account management, authentication, libraries, and watchlists.

The backend is responsible for persistence and acts as the central layer between the client application, external services, and the data layer.
