Bienvenido a la documentación en español de Movish API. Aquí encontrarás información sobre el proyecto, la arquitectura, la configuración local y el contrato HTTP de la API.

> **Estado de desarrollo:** Movish está en desarrollo activo. Algunas funcionalidades, decisiones de arquitectura y contratos pueden cambiar mientras evoluciona el proyecto.

## ¿Qué es Movish?

Movish es una plataforma para descubrir, organizar y seguir películas y series. Está diseñada para buscar en catálogos externos, gestionar una biblioteca personal, crear listas de seguimiento, marcar favoritos y controlar el estado de cada título.

La plataforma consta de dos proyectos independientes. Movish API es la aplicación backend que proporciona los datos y servicios necesarios. Movish App es la aplicación cliente que consume la API y ofrece estas funcionalidades desde los dispositivos de los usuarios.

## ¿Qué es Movish API?

Movish API es un backend Java y Spring Boot que gestiona la lógica principal de Movish App.

Su responsabilidad principal es coordinar datos de catálogos externos para que los usuarios puedan descubrir, organizar y seguir películas y series. El código actual incluye integraciones con proveedores y mantiene esos detalles externos detrás de límites de aplicación y dominio.

El proyecto incluye código de integración para proveedores como The Movie Database (TMDB). Las credenciales y URLs de proveedores se configuran mediante variables de entorno y no deben incluirse en el control de versiones. Revisa la documentación y las condiciones de uso de cada proveedor antes de utilizar sus datos.

Movish API también proporciona servicios para el registro de usuarios, la gestión de cuentas, la autenticación, las bibliotecas y las listas de seguimiento.

El backend es responsable de la persistencia y actúa como capa central entre la aplicación cliente, los servicios externos y la capa de datos.
