# Primeros pasos

Bienvenido a la documentación de Movish. En esta sección se presenta el proyecto y se explica cómo realizar la configuración inicial.

## ¿Qué es Movish?

Movish es una plataforma para dar seguimiento a tus películas y series favoritas. Te permite descubrir nuevas películas y series mediante filtros de búsqueda, crear listas y asignarles un estado según cómo las estés viendo.

La plataforma consta de dos proyectos independientes. El primero es Movish API, que funciona como un servicio backend y proporciona los datos y servicios necesarios para la plataforma. El segundo es Movish App, la aplicación que permite a los usuarios disfrutar de todas las funcionalidades que ofrece la plataforma desde sus dispositivos.

## ¿Qué es Movish API?

Movish API es el backend que gestiona la lógica principal que sustenta la aplicación móvil Movish App.

Su función principal es procesar y estructurar los datos proporcionados por The Movie Database (TMDB) para que los usuarios de Movish puedan seguir, organizar y descubrir nuevas series y películas.

The Movie Database (TMDB) es el principal proveedor de contenido utilizado por la plataforma. Los datos se obtienen a través de su API pública, disponible en la Documentación de la API de The Movie Database, y se utilizan de acuerdo con las condiciones establecidas en las Condiciones de uso de la API de The Movie Database.

Además, Movish API proporciona los servicios necesarios para la gestión de usuarios y la autenticación. Para ello, utiliza el Firebase Admin SDK para validar los tokens de autenticación enviados por la aplicación móvil.

Por otra parte, el backend es responsable de gestionar la persistencia de los datos y de proporcionar otras funcionalidades esenciales para el funcionamiento de la aplicación, actuando como punto central entre la aplicación móvil, los servicios externos y la capa de datos.
