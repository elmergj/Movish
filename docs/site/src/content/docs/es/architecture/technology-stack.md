Movish API está construida con un stack backend enfocado:

| Tecnología | Función |
| --- | --- |
| Java 21 | Lenguaje backend y versión objetivo del runtime. |
| Spring Boot 3.5 | Framework de aplicación para la API y los servicios backend. |
| Spring Web | Controllers REST y soporte para la API HTTP. |
| Spring Data JPA | Abstracción de persistencia para el modelo relacional. |
| Spring Security | Soporte de seguridad de solicitudes y autenticación. |
| Gradle Kotlin DSL | Automatización del build y gestión de dependencias. |
| PostgreSQL | Base de datos relacional y capa de persistencia. |
| MapStruct | Mapeo entre modelos de aplicación e integración. |
| Lombok | Reducción de código repetitivo en clases Java. |
| Adaptadores TMDB / OMDb | Integraciones externas de catálogos de películas y series. |
| Integración con Firebase | Soporte de autenticación y validación de tokens. |

El desarrollo local requiere JDK 21 y PostgreSQL. Consulta [Getting Started](../getting-started/) para la instalación y la configuración del entorno.
