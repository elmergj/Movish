Movish es una plataforma para descubrir, organizar y seguir películas y series.

Este sitio documenta Movish API, su arquitectura, sus integraciones y el proceso de desarrollo del proyecto. La API está construida con Java 21, Spring Boot, Gradle y PostgreSQL.

> **Estado del proyecto:** Movish está en desarrollo activo. Algunas funcionalidades, decisiones de arquitectura y contratos de API pueden cambiar.

El repositorio del proyecto está disponible en [github.com/elmergj/Movish](https://github.com/elmergj/Movish).
