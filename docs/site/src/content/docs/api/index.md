This section documents the endpoints, request formats, responses, and services exposed by Movish API.

Movish API is the backend contract consumed by Movish App. It wraps selected content from TMDB, combines it with authenticated application behavior, and exposes responses prepared for the mobile client.

This reference will grow from the currently implemented endpoints. It will document the public request and response behavior without turning this section into an internal explanation of every backend class.

Start with [authentication](./authentication), then review [endpoints](./endpoints), [data models](./data-models), and [errors](./errors).
