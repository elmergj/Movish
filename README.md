# Movish

The platform to track all your movies and series


[Movish-api]() is the part of the platform that makes everything work. It operates behind [movish-app](), managing the API, handling integrations with the provider [The Movie Database (TMDB)](https://www.themoviedb.org/), and providing all the necessary functions that allow this platform to enable users to track their favorite series and movies.
